# Verilog Projects

A collection of Digital Logic and Verilog HDL projects covering combinational circuits, sequential circuits, arithmetic units, FSMs, memory design, bus protocols, and image processing.

---

## Project Hierarchy

### 1. Digital Logic Fundamentals
- Basic Gates
- Universal Gates

### 2. Combinational Logic Circuits
- Adders
- Subtractors
- Decoders
- Encoders
- Multiplexers
- Demultiplexers
- Comparators
- Code Converters

### 3. Sequential Logic Circuits
- Latches
- Flip-Flops
- Counters
- Shift Registers

### 4. Arithmetic and Datapath Design
- Carry Save Adder
- Barrel Shifter
- Booth Multiplier
- ALU

### 5. FSM-Based Designs
- Sequence Detector
- Digital Locker
- Elevator Controller

### 6. Error Detection and Correction
- Hamming Code Generator and Detector

### 7. Memory Design
- SRAM Cell Architecture
- Decoder Based Single Port RAM
- FIFO
- SRAM Controller

### 8. Bus Protocol Design
- APB GPIO

### 9. Image Processing Hardware
- Sobel Edge Detector
